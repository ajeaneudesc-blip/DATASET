# CONTEXT BUILDER

Transforme une fiche de tâche en un dossier technique crédible.

Ajoute seulement des informations qui renforcent le réalisme :
- architecture ASCII ;
- arborescence de dépôt ;
- extraits de code ;
- schéma SQL ;
- métriques ;
- logs ;
- traces ;
- configurations ;
- dépendances ;
- historique de déploiement ;
- contraintes infrastructure ;
- exemples de données.

Ajoute quelques informations secondaires comme dans un vrai incident de production.
Ne révèle pas la cause racine.
Assure-toi que les éléments utiles à l'investigation existent réellement ou que
leur absence constitue une inconnue clairement détectable.
