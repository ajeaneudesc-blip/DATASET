# EXTREME SOFTWARE CHALLENGE

Crée un problème de niveau Distinguished Engineer.

Le système doit présenter :
- une architecture existante ;
- une contrainte de production ;
- au moins une contrainte de compatibilité ;
- une contrainte de performance ;
- une contrainte de fiabilité ;
- un composant legacy ;
- un cas limite difficile ;
- au moins deux solutions plausibles ;
- un compromis architectural réel.

Le candidat doit :
1. diagnostiquer ;
2. expliciter ses hypothèses ;
3. proposer une architecture ;
4. modifier ou écrire le code nécessaire ;
5. écrire les tests ;
6. définir les métriques ;
7. analyser les failure modes ;
8. proposer un plan de déploiement ;
9. proposer un rollback ;
10. définir les critères de validation.

Ne demande jamais une chaîne de pensée interne.
