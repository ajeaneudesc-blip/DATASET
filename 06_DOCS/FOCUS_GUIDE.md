# Focus du dataset

Répartition cible par lot :
- 60 % Problem Solving
- 40 % Machine Learning

## Problem Solving

Une tâche doit souvent demander :
- décomposition ;
- hypothèses ;
- invariants ;
- contre-exemples ;
- optimisation ;
- choix entre stratégies ;
- diagnostic ;
- décision sous incertitude ;
- validation.

## Machine Learning

Une tâche doit pouvoir porter sur :
- formulation du problème ;
- qualité et provenance des données ;
- leakage ;
- features/representations ;
- architecture ;
- loss ;
- entraînement ;
- validation ;
- robustesse ;
- drift ;
- fine-tuning ;
- distillation ;
- inference ;
- evaluation ;
- MLOps.

## Anti-générique

Éviter :
- « Quel modèle choisir ? »
- « Explique le machine learning. »
- « Conçois une API scalable. »

Préférer :
- un dataset réel et imparfait ;
- des métriques contradictoires ;
- des contraintes de coût/latence ;
- un historique de versions ;
- des erreurs difficiles à reproduire ;
- plusieurs solutions plausibles ;
- des critères de validation.
