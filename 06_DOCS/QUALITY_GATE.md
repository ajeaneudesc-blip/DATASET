# QUALITY GATE

Une tâche est ACCEPTÉE si :

- elle est réaliste ;
- la difficulté vient des interactions entre contraintes ;
- elle contient assez de contexte pour commencer ;
- les inconnues sont identifiables ;
- plusieurs solutions raisonnables existent lorsque pertinent ;
- les critères de réussite sont vérifiables ;
- le langage influence réellement la solution lorsqu'un langage est imposé ;
- les chiffres sont cohérents ;
- l'architecture est techniquement plausible ;
- la tâche ne dépend pas d'une réponse unique artificielle ;
- elle n'exige pas de révéler une chaîne de pensée interne.

REJECT si :
- c'est une question générique ;
- c'est une simple reformulation ;
- les chiffres sont contradictoires ;
- le problème n'est pas suffisamment spécifié ;
- la "difficulté" vient uniquement de la longueur ;
- la solution est donnée dans l'énoncé ;
- la tâche est offensivement exploitable en cybersécurité.
