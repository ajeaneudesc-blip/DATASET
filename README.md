# Branche `corriges` — réponses attendues des lots

Cette branche est **séparée** de l'historique du projet (branche orpheline) : elle ne contient
que les corrigés des lots de `05_OUTPUTS/`, jamais les énoncés, les scripts ou la taxonomie.

- **Ne jamais la fusionner** dans `main` ni dans une branche de travail : les énoncés doivent
  rester publiables sans leurs solutions.
- Le dépôt est **public** : ces corrigés sont lisibles par tous. Si les lots servent à évaluer des
  modèles, il faut en tenir compte (un modèle entraîné ou outillé sur le web peut y avoir accès).
  Rendre le dépôt privé, ou déplacer cette branche vers un dépôt privé, supprime ce risque pour
  l'avenir, pas pour les copies déjà faites.

## Contenu

- `batch_002/` : corrigés du lot batch_002 (20 tâches) — voir `batch_002/README.md`.

Ajouter les corrigés d'un nouveau lot dans un dossier `batch_NNN/` de même structure.
